# Find My Type — local font studio

On this Mac, double-click **Launch Find My Type.command**. Keep the terminal window open while using the tool; Control+C stops it. The launcher opens Chrome if installed, otherwise your default browser. It serves only on 127.0.0.1, accessible from this computer.

Click **Connect local fonts**. Safari uses the local Mac launcher to read installed fonts; the first scan can take a minute. Chrome and Edge use their browser font permission. Other browsers on this Mac can also use the local launcher fallback. Imported font files last for the current session.

The app runs on your computer and keeps favourites and settings in your browser. No account or hosted website is needed. Google Fonts previews still require internet to fetch fonts from Google; installed and imported fonts work offline. The included Google catalog snapshot contains 1,950 families.

If copying to another machine, Python 3 is required. You can also run `python3 serve.py` from this folder.

Category filters for local fonts, Tall, and Condensed use name-based estimates. Italics may be synthesized. Font licenses still apply.

Export shortlist downloads PNG sheets of every favourite family plus a TXT file listing font names, sources, categories, weights, style, tracking, preview size and colours. Large shortlists split into sheets of up to 18 cards. Allow multiple downloads when prompted.
